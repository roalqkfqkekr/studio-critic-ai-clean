어떻게 시작할까요?

Studio Critic AI는 로그인 없이 로컬 저장 방식으로 먼저 사용할 수 있습니다.

현재 버전은 localStorage 기반 MVP입니다. 실제 계정 로그인과 클라우드 저장은 추후 확장 기능입니다.

Project Template

어떤 프로젝트로 시작할까요?

유형을 고르면 프로젝트 브리프의 기본값만 채워집니다. 피드백과 작업 데이터 구조는 그대로 유지됩니다.
